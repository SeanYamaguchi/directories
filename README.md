#  Directories' Creator

Directories' Creatorは自動で、指定したディレクトリを指定した時刻と場所に作成できるプログラムです。ディレクトリの作成を自動化することで、より快適なデスクワークにつながると考え作りました。

ディレクトリを作成する際に決定されるのは、作成場所と日時です。また、ディレクトリのある場所は後から変更できますが、最初に作成した場所と、そして意外にも日時は変更できない要素です。これらを指定することで自在にディレクトリを作成できるようになります。本プログラムは、ディレクトリを作成する場所と日時をコマンドプロンプトから指定することで先に述べたように、ディレクトリを自在に作成することを目的としています。
